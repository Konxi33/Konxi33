# 空隙 · Konxi

> 把想法做成**能直接用的东西**，而不是又一个 demo。

现在在做一个桌面软件：**照片故事** —— 给不会排版的普通人用的摄影集工具。挑照片、写几句、导出成一本能打印的册子。

## 正在做

| 项目 | 是什么 | 技术 |
| --- | --- | --- |
| [照片故事](https://github.com/Konxi33/photo-story) | Win11 桌面软件：本地 AI 看照片打分、写文案，排版成 Word / PDF 摄影集。照片不上传，Key 只在自己电脑上 | Next.js 15 · React 19 · Electron · Tailwind v4 · IndexedDB · docx |

## 我在意的事

- **本地优先**：照片、评分、文案都在自己电脑里；云端只做「看一眼这张图」，不留存。
- **排版要像书**：页边距、字号层级、图注位置、避头尾、孤行控制——这些细节决定它是「一本书」还是「一堆截图」。
- **说人话**：界面里的每个开关都要解释清楚它为什么存在，不写「高级设置」这种糊弄人的标题。
